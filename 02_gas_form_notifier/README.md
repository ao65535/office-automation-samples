# フォーム回答の自動整理＆メール通知（Google Apps Script）

Googleフォームに回答が届いたら、受付番号を付けて一覧に整理し、担当者へ自動でメールを送るスクリプトです。

## こんなときに
- フォームの回答を毎回目で確認して、担当者に転送している
- 問い合わせに番号がなく、「どの件の話か」が分からなくなる
- 回答者への「受け付けました」メールを手で送っている

## できること
1. **受付番号を自動で付ける**：`Q-20261121-001` のように日付＋連番。同時に送信されても番号が重ならない
2. **一覧シートに整理**：受付日時・氏名・種類・内容・担当・対応状況を1行にまとめる
3. **担当者へ振り分けて通知**：「商品について」は営業、「不具合の報告」はサポート、のように種類ごとに通知先を変えられる
4. **回答者へ自動返信**：受付番号入りの受付完了メールを送る（オン・オフ可）

## 動作の流れ
```
フォーム送信
   │
   ▼
受付番号を発行（その日の連番）
   │
   ├─▶ 「受付一覧」シートに1行追加（対応状況＝未対応）
   ├─▶ 種類に応じた担当者へ通知メール
   └─▶ 回答者へ受付完了メール（メールアドレスが正しい場合のみ）
```

## 設置方法（約5分）
1. Googleフォームの「回答」タブ →「スプレッドシートにリンク」で回答用のシートを作る
2. そのシートで「拡張機能」→「Apps Script」を開き、`Code.gs` の中身を貼り付ける
3. 冒頭の `CONFIG` を書きかえる
   - `QUESTIONS`：フォームの質問名
   - `ROUTING`：種類ごとの通知先メールアドレス
   - `SHOP_NAME`：自動返信メールに入れる名前
4. 関数 `setup` を1回だけ実行する（シートの準備と、送信時に動く設定が行われます）
5. 初回は Google の権限確認画面が出るので、許可する

## テスト
Google のサービスの代わりに「にせもの」を用意して、Node.js で動作を確認しています。
```
node --test test/code.test.js
```
確認している内容：
- 受付番号が日付ごとの連番になり、行を消しても番号が重ならない
- 名前の空白・メールアドレスの大文字がそろう
- 種類に応じて通知先が変わる
- 送信1件につき、シートに1行追加され、担当者と回答者にメールが届く
- メールアドレスが不正なら、自動返信を送らない

## カスタマイズの例
- メールの代わりに Slack・Chatwork・LINE へ通知
- 対応状況が「対応済み」になったら回答者へ連絡
- 毎朝、未対応の件数をまとめて送る

## 注意
- Gmail の無料アカウントは、1日に送れるメールの数に上限があります（Google Workspace はより多い）
