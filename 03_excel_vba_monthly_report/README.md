# 月別・店舗別 売上集計マクロ（Excel VBA）

店舗ごとに分かれた売上シートを、ボタン1つで「月 × 店舗」の表とグラフにまとめるマクロです。

## こんなときに
- 毎月、各店舗（各担当者）のシートをコピーして集計表を作っている
- ピボットテーブルを毎回作り直すのが面倒
- 入力ミスのある行があると、集計がずれてしまう

## できること
1. **A1セルが「日付」のシートを自動で見つけて**、すべて読み込む（店舗が増えてもマクロの修正は不要）
2. **「集計」シートを作り直して**、次の3つを作る
   - 月 × 店舗 の売上表（合計行・合計列付き）
   - 月別・店舗別の棒グラフ
   - 商品別の売上ランキング
3. **集計できない行はスキップ**して、件数を最後に知らせる（日付が「未定」、金額が空欄 など）

## データの形
各店舗のシートを、次の形にそろえます（シート名が店舗名になります）。

| 日付 | 商品 | 数量 | 金額 |
|---|---|---|---|
| 2026/07/03 | コーヒー豆 200g | 2 | 2,400 |
| 2026/07/05 | マグカップ | 1 | 1,800 |

## 集計結果（sample_sales.xlsx の場合）
| 月 | 東京店 | 大阪店 | 名古屋店 | 合計 |
|---|---:|---:|---:|---:|
| 2026-07 | 103,260 | 84,060 | 97,960 | 285,280 |
| 2026-08 | 78,980 | 81,260 | 114,020 | 274,260 |
| 2026-09 | 119,440 | 64,400 | 53,140 | 236,980 |
| **合計** | **301,680** | **229,720** | **265,120** | **796,520** |

| 商品 | 数量 | 金額 |
|---|---:|---:|
| ギフトセット | 97 | 339,500 |
| マグカップ | 105 | 189,000 |
| コーヒー豆 200g | 118 | 141,600 |
| ドリップバッグ 10袋 | 129 | 126,420 |

各シートの最後の行（日付が「未定」）はスキップされ、「スキップした行：3 行」と表示されます。

## 使い方
1. `sample_sales.xlsx`（または自分のファイル）を開く
2. `Alt + F11` で VBA の画面を開く
3. 「挿入」→「標準モジュール」を選び、`MonthlyReport.bas` の中身をすべて貼り付ける
4. VBA の画面を閉じ、`Alt + F8` →「CreateMonthlySummary」→「実行」
5. 次回以降も使う場合は「Excel マクロ有効ブック（.xlsm）」で保存する

ボタンから実行したい場合は、「開発」タブ →「挿入」→「ボタン」で、マクロ「CreateMonthlySummary」を割り当てます。

## 工夫した点
- データを1セルずつではなく**配列で一括読み込み**しているので、数万行でもすぐに終わる
- 「2026-07」が Excel に日付として自動変換されないよう、月の列を文字列にしている
- エラーが起きても、画面の更新や確認メッセージの設定を必ず元に戻す

## サンプルデータの作り直し
```
pip install openpyxl
python make_sample_data.py
```
正解の集計値も画面に表示されるので、マクロの結果と見比べられます。

## カスタマイズの例
- 担当者別・商品カテゴリ別の集計
- 前年同月比・目標達成率の列を追加
- 集計結果を PDF にして保存、メールで送信
