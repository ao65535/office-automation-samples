# 業務自動化サンプル集

Excel・Googleスプレッドシート・CSV の「毎回の手作業」を自動化するサンプルです。
どれもテスト済みで、使い方の説明書を付けています。

| # | サンプル | 使う技術 | 何が楽になるか |
|---|---|---|---|
| 1 | [CSV整形・重複チェック](01_python_csv_cleaner/) | Python | 表記ゆれのある名簿を整え、重複と入力ミスを自動で見つける |
| 2 | [フォーム回答の自動整理＆メール通知](02_gas_form_notifier/) | Google Apps Script | フォームの回答に受付番号を付けて一覧化し、担当者と回答者へ自動でメール |
| 3 | [月別・店舗別 売上集計](03_excel_vba_monthly_report/) | Excel VBA | 店舗ごとのシートを、ボタン1つで集計表・グラフ・ランキングに |

## 大切にしていること
- **動作確認してから納品**：サンプルデータと自動テストで確認しています
- **使う人が困らない説明書**：設置手順と、よくある変更の方法を書いています
- **入力ミスに強い**：おかしなデータは止まらずにスキップし、どこがおかしいかを知らせます
