# CSV整形・重複チェックツール（Python）

顧客名簿や申込者リストのCSVを、ボタン1つで「そろった形」に整えるツールです。

## こんなときに
- 表記がバラバラ（全角・半角、ハイフンの有無、日付の書き方）で集計できない
- 同じ人が二重に登録されていないか、目で探している
- 入力ミス（桁数の足りない電話番号、形式の誤ったメールアドレス）を見つけたい

## できること
| 項目 | 整形の内容 | 例 |
|---|---|---|
| 氏名 | 前後の空白を消し、姓と名の間を半角スペース1つに | `　山田　太郎` → `山田 太郎` |
| メールアドレス | 全角→半角、小文字にそろえる。形式の誤りを検出 | `Ｔａｒｏ@Example.COM` → `taro@example.com` |
| 電話番号 | 全角→半角、ハイフン区切りにそろえる。桁数の誤りを検出 | `０８０（１１１１）２２２２` → `080-1111-2222` |
| 郵便番号 | `123-4567` の形にそろえる。桁数の誤りを検出 | `５３００００１` → `530-0001` |
| 日付 | `YYYY-MM-DD` にそろえる。ありえない日付を検出 | `2026年2月14日` → `2026-02-14` |
| 重複 | メールアドレス（ない場合は氏名＋電話番号）で判定 | 重複行は別ファイルへ |

問題のあった行には「要確認」列に理由が入るので、人が確認すべき行だけを見ればよくなります。

## 実行結果（サンプルデータ）
```
> python clean_csv.py sample_input.csv output
読み込み: 9件
整形後  : 7件 -> output/cleaned.csv
重複    : 2件 -> output/duplicates.csv
要確認  : 2件（「要確認」列に理由を記載）
```

| 入力（sample_input.csv） | 出力（cleaned.csv） |
|---|---|
| `　山田　太郎, Taro.Yamada@Example.com, 090-1234-5678, 100-0001, 2026/1/5` | `山田 太郎, taro.yamada@example.com, 090-1234-5678, 100-0001, 2026-01-05` |
| `鈴木 花子, …, ０８０（１１１１）２２２２, ５３００００１, 2026年2月14日` | `鈴木 花子, …, 080-1111-2222, 530-0001, 2026-02-14` |
| `伊藤 さくら, …, 090-5555-666, …, 2026/13/1` | 要確認：`電話番号の桁数、日付の形式` |

## 使い方
1. Python 3.10 以上をインストール（追加のライブラリは不要）
2. `clean_csv.py` 冒頭の列名を、実際のCSVの見出しに合わせる
3. 実行する
   ```
   python clean_csv.py 入力ファイル.csv 出力フォルダ
   ```
- 文字コードは UTF-8・Shift_JIS のどちらでも読み込めます
- 出力は Excel で文字化けしない形式（BOM付きUTF-8）です
